# Invoice Generator

A simple and user-friendly Invoice Generator application designed to help users create professional invoices quickly and easily.

## Features
- Create professional invoices.
- Manage customer information.
- Add products and services.
- Automatically calculate subtotal and total payments.
- Generate and download invoices.
- Simple and responsive user interface.

## Purpose
This project aims to simplify the invoicing process for individuals, freelancers, and small businesses.
